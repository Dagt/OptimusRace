# MODNet portrait processing

MODNet: A Trimap-Free Portrait Matting Solution in Real Time, Zhanghan Ke and contributors.
Original code and pretrained models: https://github.com/ZHKKKe/MODNet
ONNX conversion: Xenova, https://huggingface.co/Xenova/modnet
Model revision: fa2fa546052fba4c08921230a26cc69a333fca12
SHA-256: 07c308cf0fc7e6e8b2065a12ed7fc07e1de8febb7dc7839d7b7f15dd66584df9

The model is downloaded unmodified under Apache-2.0. See the accompanying license. Processing in Optimus Race adds resizing, gentle contrast/sharpness adjustment and a separate client-side frame and background. No face or pose generation is performed.
