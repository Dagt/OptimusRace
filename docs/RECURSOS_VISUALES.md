# Recursos visuales y licencias

## Imagen editorial

Archivo integrado: `static/images/campaign.png`. Creado con la herramienta nativa ImageGen y la skill imagegen, sin reutilizar fotografía ni identidad del usuario. Brief utilizado: fotografía editorial deportiva premium de atleta ficticio adulto en gimnasio oscuro, encuadre a la derecha, camiseta negra sin marcas, iluminación cálida dorada y espacio negativo a la izquierda para titular. Estética natural, cinematográfica, sin texto ni logotipos. Mujer adulta desenfocada en fondo. La imagen se conserva para la portada de marca. Los perfiles sin foto muestran iniciales; cada usuario puede subir su foto.

El JPEG proporcionado se conservó como referencia de negro/dorado y composición. No se incorporó su identidad como atleta DEMO.

## Tipografías

Barlow Condensed y DM Sans de Google Fonts. Archivos Latin WOFF2 locales bajo static/fonts. Licencias SIL Open Font License incluidas como barlowcondensed-OFL.txt y dmsans-OFL.txt. Script reproducible: scripts/vendor_fonts.py. La aplicación no consulta Google Fonts durante uso normal.

## Gráficas e iconos

Chart.js 4.5.1, licencia MIT incluida en static/vendor/CHART-LICENSE.md. Script de descarga fijada: scripts/vendor_chart.py. [Documentación oficial](https://www.chartjs.org/docs/latest/). Los datos de gráficos provienen de registros/reglas de cada edición.

Iconos SVG, monograma O/R y sistema CSS creados para esta interfaz. No se usa una biblioteca externa de iconos.
